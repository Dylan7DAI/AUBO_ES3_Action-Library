# AUBO ES3 真机安全检查清单

每次首次运行新代码、修改运动参数、修改工具或改变工位后，都应重新执行本清单。

## A. 软件检查

- [ ] 当前运行的是 `aubo` Conda 环境，SDK 版本已经记录。
- [ ] 已先运行 `diagnose_robot.py`，机器人名称、关节角和 TCP 位姿合理。
- [ ] 本地配置文件没有提交到 Git。
- [ ] `joint_min_rad` / `joint_max_rad` 已按当前 ES3 和现场限制核实。
- [ ] `max_delta_rad` 足够小，首次建议不超过 0.02 rad。
- [ ] 速度和加速度处于低值。
- [ ] 已先运行不带 `--execute` 的 dry-run，并逐关节检查预览。
- [ ] 增量的单位确认是 rad，而不是 degree。
- [ ] 关节顺序已与示教器/SDK确认。

## B. 现场检查

- [ ] 急停按钮可达并确认有效。
- [ ] 操作人员站在机械臂工作空间之外。
- [ ] 工作空间内无人、无松动物体、无临时工具。
- [ ] 机械臂、夹爪、线缆不会撞击工装、桌面、围栏或自身。
- [ ] 当前姿态有足够空间执行指定方向的小增量。
- [ ] 现场有第二名人员监护，首次测试建议执行。
- [ ] 控制器允许远程控制，且当前运行模式已确认。

## C. 执行中

- [ ] 手保持在急停附近，但不进入工作空间。
- [ ] 只执行单次、小幅、低速动作。
- [ ] 机械臂运动方向与预期不一致时立即急停。
- [ ] 出现异响、抖动、通信异常或保护停止时，不盲目重试。

## D. 执行后

- [ ] 记录命令、当前姿态、目标姿态和返回值。
- [ ] 确认机器人稳定停在安全位置。
- [ ] 对任何异常进行归因后才允许下一次测试。
